# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately through GitHub:
**Security** tab → **Report a vulnerability**.

Include the affected version, how to reproduce the problem and, if you can, its impact. You get an answer as soon as someone has looked at the report.

The webhook serves secrets from a KeePass database, so reports about authentication, token handling, request parsing and the container image are especially welcome.
